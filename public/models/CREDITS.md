# Personajes de SoulSync

Caballero, Bárbaro, Pícaro y Mago usan **KayKit: Adventurers Character Pack (1.0)**, de Kay Lousberg (www.kaylousberg.com).
Fuente: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
Licencia: **CC0 1.0** (ver KAYKIT_LICENSE.txt).
Los modelos se recortaron con `scripts/build-avatars.mjs` para conservar un set de accesorios por arquetipo y las animaciones Idle, Walking_A y Cheer.
